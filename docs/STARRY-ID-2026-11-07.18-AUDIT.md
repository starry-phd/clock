## 2026-11-07.18 新需求的具體實作

### 會員頭像與縮寫

- **Expo 和 Web 同步**於中央會員設定顯示 `GET /v1/me` 的 `profile.avatar_url`，不下載保存成自己檔案、不做頭像上傳；每次進入帳號畫面重新取得，因為簽名網址只有一小時效期。
- `avatar_url=null`、圖片讀取失敗時顯示中央 `profile.initials`，不自行由姓名計算。空值才使用 `?` 佔位。
- Web 的 Cloudflare Worker CSP 只額外放行 `https://id.starry.phd` 的簽名頭像圖片，仍不允許任意外部圖片或把機密資料放進前端；圖片請求採 `no-referrer`。

### 可變會員編號／公開頁／邀請

- `member_no` 只做**顯示及公開網址代碼**，接受 **國碼 2 位大寫字母＋7～10 位數字**，絕不可作主鍵、檔名或個人用途 D1 的所有權鍵。免費計時器、付費用途仍以 JWT 驗證後的 **`user_id`** 管理。
- Expo 設定頁新增會員編號、`https://id.starry.phd/<member_no>` 公開頁、`https://id.starry.phd/Invite/<member_no>` 邀請分享；以 `Share.share()` 呼叫原生分享表單，開啟公開頁或分享前均重新讀 `/v1/me`，防止會員在中央改號後分享舊碼。
- Web 會員設定頁同樣顯示編號、公開頁、分享邀請網址；使用 Web Share API／複製連結／手動複製備援；每次開啟連結前重新讀取當前會員編號。未登入或中央未提供合法編號時不顯示分享按鈕。
- 邀請連結用 `/Invite/`（**尾端一定有斜線再接完整號碼**），不可漏掉斜線，也不能假設號碼為固定 7 位數。

### 普通／量子電池圖示

- Expo 與 Web 設定頁的額度改為 `🔋 {remaining} 顆普通電池`、`⚛️ {available} 顆量子電池`。計時器新增、免費取代、Owner 設定等所有使用者可見扣量文字同步標明 `🔋`，不以其他圖示替代。
- 不因顯示圖示而改變任何扣量條件、價格、中央餘額或收費開關。
