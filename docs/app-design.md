# 產品與技術決議

- 名稱：Clock（`clock`）。
- 主用途：超大倒數及時鐘。
- 模式：倒數 `mm:ss`，時鐘 `HH:mm:ss`。
- 用途預設：休息 05:00、開場致詞 03:00、主題分享 20:00；可新增、編輯、刪除，1～50 種。
- 提醒：可設定提前 0～120 秒單次提示，歸零再鳴響；音效可關閉。
- 使用體驗：深色高對比、極大數字、橫直自適應、全螢幕、少按鈕。
- 儲存：瀏覽器 localStorage；Expo 原生 AsyncStorage；不存敏感會員資料。
- 計時：開始時計算結束時間，每次刷新以當下時間計算剩餘，暫停即保存剩餘毫秒。
- 會員：API 契約只讀；不動中央系統；未完成 Clock App 註冊及 OAuth。
- 本版沒有：廣告（AdMob 官方供應商已選、Ads OFF）、Billing、Battery、D1、R2、支付及大型後台。
- 安全：Web 上不存 OAuth Token，原生取得合法 Token 後應使用系統加密儲存；本版未實作登入。
- 限制：瀏覽器/OS 限制背景提醒，無法保證鎖屏後準時響鈴；需要強可靠背景通知須另行設計與驗證。
