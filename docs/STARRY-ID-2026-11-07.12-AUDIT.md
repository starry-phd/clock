## 本版新增重點：裝置共用登入（SSO，第 13.5 節）

- **iOS 已接線，尚未實機驗收**：Clock `app.json` 使用 `$(AppIdentifierPrefix)phd.starry.sso` 共用 Keychain group（不硬編 Apple Team ID），`expo-secure-store` 用同一 `starry-sso-v1` service 存取 `starry.sso`。傳給官方 SDK 的 `sharedStorage`；登入、App 啟動、返回前景呼叫官方 `syncDeviceSignIn()`；舊版本 Refresh Token 鍵保留。修補「別的 App 登出後本 App 因暫存 Access Token 恢復已登出身分」：Clock 額外使用本機曾見過 SSO 的標記，偵測共用 token 被清除時安全登出。
- **其他繁星 iOS App 必須同步**使用相同的 Keychain Access Group、service 與 Starry 官方 SDK sharedStorage，並採用同一 Apple 開發團隊簽章／具對應 entitlement 的 provisioning profile；只修改 Clock 無法讓未升級的其他 App 同步登出。Apple Team ID 不由 Clock 設定。
- **Android 跨 App 共用登入尚未符合**：Expo SecureStore 及 Android SharedPreferences 都是 App 私有。由於 Android 必須先有安全的同簽章 Account 或 Signature Permission ContentProvider，且每一款繁星 Android App 都必須採用相同元件／簽章、Play 版可與 EAS Preview 不同，Clock 不得拿 App 私有 SecureStore 假冒跨 App 共享。待全生態系共同訂定 Provider／Account 契約和共用 Android 簽章後再啟用 `sharedStorage`，**不在此 PR 宣稱 Android SSO 完成**。
- **Web**：官方 SDK 的 Web 版用 sessionStorage（不寫 Refresh Token 到 localStorage）；不同網域不能直接共享 Web 儲存。登入使用 Starry Relay 及共用 Passkey，不冒充原生裝置共享 SSO。
- **文案**：iOS 顯示「登出所有繁星 App」；Android 在跨 App 儲存未完成前顯示「登出 Clock（Android 共用登入待驗證）」；「登出所有裝置」仍透過中央 logout-all。
